#Used Car Price Prediction
This project builds a regression model to estimate the market price of a used car. It walks through the full ML pipeline: data cleaning, feature engineering, exploratory data analysis (EDA), model training, and evaluation.

What it does
-Cleans raw used car data (price, mileage, engine size, etc.)
-Encodes features like brand, fuel type, accident history
-Trains a Linear Regression model
-Evaluates using R², MAE, and RMSE

Results
Model predicts used car prices based on mileage, car age, engine size, brand, fuel type, and accident history.
